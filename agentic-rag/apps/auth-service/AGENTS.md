# AUTH SERVICE

Go 1.23 authentication/authorization service: ConnectRPC + Ory Kratos + SpiceDB.

## STRUCTURE

```
auth-service/
├── cmd/server/main.go       # Entry point — server setup, graceful shutdown
├── internal/
│   ├── config/              # Env-based config loading (service URLs, credentials)
│   ├── domain/              # models.go (User, Session), errors.go (domain errors)
│   ├── handler/             # identity.go (Login, WhoAmI), permission.go (CheckPermission)
│   ├── middleware/          # auth.go (HTTP session validation), authz.go (RPC interceptor)
│   └── infrastructure/
│       ├── kratos/          # Ory Kratos client (session validation, trait extraction)
│       └── spicedb/         # SpiceDB client (relationship CRUD, permission checks)
├── gen/                     # Generated protobuf + ConnectRPC (DO NOT EDIT)
├── buf.yaml                 # Buf config with lint + breaking change detection
└── buf.gen.yaml             # Go + ConnectRPC code generation
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| Add RPC method | `internal/handler/` | Implement generated interface |
| Add middleware | `internal/middleware/` | HTTP handler wrapper or Connect interceptor |
| Domain errors | `internal/domain/errors.go` | ErrUnauthenticated, ErrSessionInactive |
| Domain models | `internal/domain/models.go` | User, Session structs + repo interfaces |
| Kratos integration | `internal/infrastructure/kratos/` | Session validation, trait extraction |
| Permission checks | `internal/infrastructure/spicedb/` | WriteRelationship, CheckPermission |
| Configuration | `internal/config/config.go` | Env vars with defaults |

## CONVENTIONS

- **Layout**: Standard Go `cmd/` + `internal/`
- **Logging**: `slog` with JSON handler — `slog.Info("msg", "key", val)`
- **RPC**: ConnectRPC handlers implement generated interfaces; `var _ Interface = (*Handler)(nil)` for compile-time checks
- **Auth flow**: HTTP middleware (Kratos session) → ConnectRPC interceptor (SpiceDB authz)
- **Errors**: Domain errors in `errors.go`, wrapped at handler boundaries with connect error codes
- **HTTP/2**: h2c (cleartext HTTP/2) for internal container-to-container communication

## PATTERNS

### Handler Implementation
```go
type IdentityHandler struct {
    kratos *kratos.Client
}

func (h *IdentityHandler) Login(ctx context.Context, req *connect.Request[authv1.LoginRequest]) (*connect.Response[authv1.LoginResponse], error) {
    // Delegate to infrastructure client, wrap errors with connect codes
}
```

### Middleware Context
```go
userID := middleware.GetUserID(ctx)    // Set by auth middleware
email := middleware.GetUserEmail(ctx)  // Extracted from Kratos session traits
```

### Dual Auth Support
Middleware accepts both cookie-based sessions and `Authorization: Bearer` header.

## ANTI-PATTERNS

- **NO** editing `gen/` — regenerated by `bun run codegen`
- **NO** direct database access — use infrastructure clients (kratos/, spicedb/)
- **NO** panics in handlers — return connect errors with proper codes
- **NO** hardcoded service URLs — use config from environment

## NOTES

- Server listens on `:8081` (configurable via `AUTH_SERVER_ADDR`)
- Graceful shutdown with 30s timeout
