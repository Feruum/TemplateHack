# ADMIN DASHBOARD

Next.js 16 + React 19 + Tailwind 4 frontend. ConnectRPC for typed API calls to auth-service and agent.

## STRUCTURE

```
src/
├── app/                 # Next.js App Router
│   ├── layout.tsx       # Root layout — Providers, Geist fonts
│   ├── (files)/         # Route group: files, chat, folder, recent, shared, starred, trash
│   └── api/agent/       # API route — proxies streaming chat to agent service
├── components/
│   ├── ai-elements/     # Chat UI: prompt-input, message, conversation (complex, 1100+ lines)
│   ├── chat/            # Chat panel with sources + tool call display
│   ├── files/           # File management components
│   └── ui/              # Radix primitives (22 components, import directly — no barrel)
├── gen/                 # Generated protobuf (DO NOT EDIT)
├── hooks/               # useAgentChat (SSE streaming), use-mobile, use-typewriter
├── lib/                 # transport.ts, constants.ts, utils.ts
├── mock-data/           # Development mock data
└── store/               # Zustand stores (files-store.ts)
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| Add page | `src/app/` | App Router, route groups with `()` |
| Add component | `src/components/` | Radix + CVA + Tailwind |
| Add hook | `src/hooks/` | Custom React hooks |
| API transport | `src/lib/transport.ts` | ConnectRPC transport config |
| Service URLs | `src/lib/constants.ts` | `NEXT_PUBLIC_` env vars |
| State management | `src/store/` | Zustand stores |
| Chat streaming | `src/hooks/use-agent-chat.ts` | SSE parsing, tool call tracking |
| Providers | `src/components/providers.tsx` | QueryClient, TransportProvider, ThemeProvider |

## CONVENTIONS

- **Imports**: `@/` prefix → `src/`
- **Linter/Formatter**: **Biome** (not ESLint/Prettier) — double quotes, 100 line width
- **API calls**: TanStack Query + ConnectRPC (`@connectrpc/connect-query`)
- **Styling**: Tailwind 4 + `cn()` from `@/lib/utils` (clsx + tailwind-merge)
- **Forms**: React Hook Form + Zod 4 validation
- **Components**: `class-variance-authority` (CVA) for variants
- **State**: Zustand for global state, `useRef` for mutable non-reactive values
- **Icons**: HugeIcons (`@hugeicons/react`) + Lucide

## PATTERNS

### Service Consumption
```typescript
import { AdminService } from "@/gen/admin/v1/admin_pb"
import { useQuery } from "@connectrpc/connect-query"

const { data } = useQuery(AdminService.method.listDocuments, {...})
```

### API Proxying
Next.js rewrites `/api/auth/*` → auth-service, `/api/agent/*` → agent service.
Configured in `next.config.ts` using env vars `AUTH_SERVICE_URL` / `AGENT_SERVICE_URL`.

### Component Variants
```typescript
const buttonVariants = cva("base-classes", {
  variants: { size: { sm: "...", lg: "..." } }
})
```

## ANTI-PATTERNS

- **NO** editing `src/gen/` — regenerated by `bun run codegen`
- **NO** hardcoded localhost URLs — use `constants.ts` → env vars
- **NO** CSS modules — Tailwind only
- **NO** `as any`, `@ts-ignore`, `@ts-expect-error`
- **NO** ESLint/Prettier — use Biome

## NOTES
